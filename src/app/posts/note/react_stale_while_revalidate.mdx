# stale-while-revalidate 전략은 캐시된 데이터를 먼저 보여주고, 백그라운드에서 데이터를 갱신하는 방법이다.

- React Query 전체를 관통하는 단 하나의 철학
- 화면 전환 시 스피너가 안 뜨는 이유: 캐시를 즉시 그리고, 갱신은 백그라운드에서 하기 때문
- 이걸 이해하면 isLoading 과 isFetching 의 차이를 이해할 수 있다.
