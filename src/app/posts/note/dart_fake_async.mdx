# Fake Async를 사용하여, 실제로 기다리지 않고 임의 시점을 검증한다.

한 줄 정의: 시간 delay가 걸려있는 모든 Dart/Flutter 코드를 '기다림 없이 instantly' 테스트하기 위한 타임머신

## Delay 예시

- Future.delayed
- Timer
- Timer.periodic
- 애니메이션 / 디바운싱(Debouncing)
